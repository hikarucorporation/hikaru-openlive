Lo más valioso: el patch Pd completo

El archivo EBPhaselock.pd es el algoritmo entero del phaser, extraído del binario. Es un patch de Pure Data (librería ELSE) que:
- Recibe audio (inlet~), cutoff (Hz) y order (número de polos, 2..100)
- Calcula coeficientes de biquad por polo: g, re, im, r, phi
- Aplica los biquads en cascada con biquads~
- Tiene clear para resetear el estado
- Usa la FFT de Mayer para el procesamiento espectral

Es un phaser de N polos con cutoff variable — esencialmente un "AU5-style" phaser, como sospechabas.

El resto del reporte

El README.md documenta:
- La identidad del plugin (CRQL, v1.0.4, VST 3.8.0)
